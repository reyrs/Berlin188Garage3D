# Panduan Video Animasi Garasi Berlin 188

Tempatkan file video hasil generate Google Gemini / Google Veo di folder ini dengan nama:
`garage-cinematic.mp4`

### Rekomendasi Format Video:
- **Nama File**: `garage-cinematic.mp4`
- **Format**: MP4 (H.264 / AAC)
- **Resolusi**: 1920x1080 (1080p Widescreen) atau 3840x2160 (4K)
- **Frame Rate**: 24 fps atau 30 fps
- **Gaya Pengambilan**: 1 Continuous Take (satu shot kontinu, camera slow glide maju, tanpa pemotongan / no cuts)
- **Durasi**: 10 – 15 detik (sekitar 240 – 360 frame)

Setelah file `garage-cinematic.mp4` diletakkan di folder ini, halaman `/garasi/` (mode Animasi Scroll Video) akan otomatis mendeteksi video dan memutarnya frame-by-frame mengikuti scroll mouse/layar.
